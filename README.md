## ⚡ أسرع طريقة تجيب الـ APK (من غير ما تنصّب أي حاجة)

الرفع على GitHub وهو يبني لك الـ APK مجانًا:

1. اعمل حساب على [github.com](https://github.com) لو مش عندك، واعمل **New repository** باسم `tasneem` (اختار Public).
2. اضغط **uploading an existing file** وارفع **كل** محتويات مجلد `tasneem` (مهم: بما فيه المجلد المخفي `.github`). لو الرفع من الموبايل، فك الضغط الأول ببرنامج زي ZArchiver وارفع الملفات.
3. افتح تبويب **Actions** ← اختر «بناء تطبيق تسنيم (APK)» ← **Run workflow**.
4. استنى ٥–٨ دقايق، وبعدين انزل تحت في صفحة التشغيل وهتلاقي **tasneem-apk** جاهز للتنزيل.
5. فك الضغط، وثبّت `app-debug.apk` على الفون (هيطلب إذن «تثبيت من مصدر غير معروف» — وافق).

الورك فلو بيعمل كل حاجة لوحده: ينزّل المصحف جوّه التطبيق، ينشئ مشروع أندرويد،
يضيف كود الجافا والأذونات، ويبني الـ APK.

## 🖥️ أو من الكمبيوتر بأمر واحد

محتاج: Node.js 20+ و JDK 21 و Android SDK.

```bash
cd tasneem
npm install
npm run all      # ينزّل المصحف + يجهّز أندرويد + يبني الـ APK
```
الملف هيطلع في: `android/app/build/outputs/apk/debug/app-debug.apk`

> ملاحظة: الصوت (الأذان والصلاة على النبي) محتاج ملفات mp3 تحطها بنفسك في
> `android/app/src/main/res/raw/` بأسماء: `adhan.mp3` و`adhan_fajr.mp3` و`salawat.mp3`.
> من غيرها التطبيق شغال ١٠٠٪ بس الإشعار بصوت الهاتف الافتراضي.

## ٢. بناء APK لأندرويد

```bash
cd tasneem
npm install
npx cap add android
npx cap sync android
```

### ثم أضف الجزء الأصلي (المهم جدًا)

انسخ ملفات جافا من `android-native/` إلى:
```
android/app/src/main/java/com/tasneem/athkar/
```
وهي: `DhikrService.java` · `BootReceiver.java` · `AdhanReceiver.java` · `TasneemPlugin.java`

استبدل `MainActivity.java` بالنسخة في `android-native/MainActivity-snippet.java`
(بتضيف سطر `registerPlugin(TasneemPlugin.class)`).

افتح `android/app/src/main/AndroidManifest.xml` وضيف اللي في
`android-native/AndroidManifest-additions.xml` (الأذونات + الخدمة + المستقبِلات).

### ملفات الصوت

اعمل مجلد `android/app/src/main/res/raw/` وحط فيه:

| الملف | الاستخدام |
|---|---|
| `adhan.mp3` | الأذان العادي |
| `adhan_fajr.mp3` | أذان الفجر |
| `salawat.mp3` | الصلاة على النبي عند فتح الهاتف |

(الأسماء لازم تكون حروف صغيرة وبدون مسافات). التطبيق بيشتغل من غيرها بس من غير صوت.

### البناء

```bash
cd android && ./gradlew assembleDebug
```
الـ APK هيطلع في `android/app/build/outputs/apk/debug/app-debug.apk`

## ٣. حاجات مهمة على أندرويد الحديث

1. **الصلاة على النبي عند فتح الفون**: أندرويد ٨ فما فوق بيمنع `ACTION_USER_PRESENT`
   من الـ Manifest، عشان كده الكود بيسجّله وقت التشغيل من `DhikrService` اللي شغالة
   في المقدمة (Foreground Service) بإشعار صغير دايم. ده نفس اللي بتعمله تطبيقات
   «الشفيع» وغيرها — الإشعار الدايم ده مش اختياري، من غيره النظام بيقفل الخدمة.

2. **استثناء من توفير البطارية**: لازم المستخدم يوافق، وإلا شاومي/سامسونج/هواوي
   هيقفلوا الخدمة. ضيف شاشة ترحيب توجّهه للإعدادات.

3. **الأذان أطول من ٣٠ ثانية** — عشان كده مش بنستخدم صوت الإشعار العادي،
   لكن `MediaPlayer` من `AdhanReceiver` مع `USAGE_ALARM`.

4. **إذن الإشعارات** مطلوب من أندرويد ١٣ (`POST_NOTIFICATIONS`).

## ٤. مصدر بيانات المصحف

`https://api.alquran.cloud/v1/quran/quran-uthmani` — نص عثماني كامل مع رقم الصفحة
والجزء لكل آية، وفيه مصدر احتياطي تاني في `js/quran.js`.
بيتخزّن في IndexedDB على الجهاز، فالتنزيل بيحصل **مرة واحدة بس**.

لو عايز التطبيق يشتغل أوفلاين من أول تشغيل: نزّل الـ JSON مرة، حوّله لملف
`www/data/quran.json`، وغيّر أول عنصر في `SOURCES` لـ `data/quran.json`.
